### Implementation notes
- `parse_times` uses `TIME_FORMATS` for day-of-year parsing with fallback to generic `pd.to_datetime(errors='coerce')`.
- Valid times are selected via `parsed.notna()`. Max time is computed, ties resolved by picking the last candidate by original index for deterministic behavior.
- Groups with no usable times fall back to `group.iloc[-1]` for deterministic missing-time handling.
- Value-specific path returns a single-row `DemosatChannelFrame` preserving type.
- Both paths wrap results with `self.__class__(..., coerce=False, validate=False)` to preserve frame type.
