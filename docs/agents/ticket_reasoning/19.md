# Ticket 19 Reasoning

## Summary
Created small representative sample CSVs for EHA and EVR simulation data under `examples/data/` to support smoke testing of demosat_data_utils exit-condition gates.

## Decisions
- Used exact column headers from source fixtures in `demosat_seq/examples/sim_outputs/` to ensure compatibility with existing readers.
- For `sim_eha_sample.csv`, synthesized rows based on a real YAW_ANGLE row template, modifying `dnAlarmState`/`euAlarmState` to cover required cases: no-alarm, DN yellow, EU yellow, DN red, EU red, red-over-yellow precedence, and mixed-case values (`RED`, `YELLOW`).
- Kept sample to 8 rows (< few hundred) for fast notebook execution.
- For `sim_evr_sample.csv`, copied header and three normal event rows plus one `SIM_ERROR` row directly from source fixtures to preserve realistic quoting and metadata format.
- Placed files under `examples/data/` which is not gitignored.

## Trade-offs
- Source `simulated_eha.csv` contains no alarm states in the current fixture. Rather than shipping an empty sample, synthetic alarm rows were created using the same schema and representative channel values. This satisfies acceptance criteria while staying faithful to column layout.
- EVR sample uses a minimal set of rows; could be expanded later but sufficient for smoke test and SIM_ERROR gate.

## Verification
- Files exist and contain correct headers.
- EHA sample includes all required alarm scenarios and mixed case.
- EVR sample includes SIM_ERROR row.
- Ready for commit.
